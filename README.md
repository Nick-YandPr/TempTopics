## Как пособие Git
Я расскажу, как им пользоваться в рамках данного мне задания от Яндекс Практикум!
Для начала тебе стоит понять, что работа с Git это в первую очередь работа с командной строкой. Начнёшь с Gui - просто ничего не поймёшь...
Для комфортной работы нужно научиться перемещаться по директории, потому что работать инструментами Git приходится в нужной папке - нужно привести его туда.  
Существует 2 операции в гит: загрузка локального репозитория в удалённый и выгрузка (копирование актуальной версии локально на машину)
### Загрузка (перед этим привязать удалён репозиторий к )
1. Нужно подготовить папку для работы SVC с ней - создать данные для трекинга в скрытой папке .git
В командной строке перейти в нужную папку и вызвать:
```bash
git init
```
2. Запомнить файлы к отслеживанию
Для всех файлов и папок по данному пути
```bash
git add .
```
Для всех файлов (не папок)
```bash
git add --all
```
3. Сделать коммит (фиксация текущего содержимого в SVC локально)
```bash
git commit
```
4. Теперь у тебя локально отслеживаются версии, чтобы отслеживать глобально, нужно создать репозиторий на GitHub.
5. С помощью ссылки на этот репозиторий (там будет отображаться после создания) или через SSH ключи (изучи сам) нужно выполнить команды:
(Команды предоставлены для варианта с ссылкой)
```bash
git remote add origin https://github.com/practicum-git/first-project.git
git branch -M main
git push -u origin main
```
### Выгрузка
```bash
git clone ССЫЛКА_НА_УДАЛЁННЫЙ_РЕПОЗИТОРИЙ
```
